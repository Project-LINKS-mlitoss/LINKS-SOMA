# サンプルデータ・テンプレートデータ
## 1. サンプルデータとは
LINKS SOMAの各操作を体験するためのデータです。東京都千代田区の住所をベースに、ダミーの空き家推定を実行することができます。詳細の操作方法は、LINKS SOMAの操作マニュアルを参照してください。

サンプルデータを利用する際は、「関東地方」版のアプリをご利用ください。

[データをダウンロード](https://storage.googleapis.com/links-soma/example/%E3%82%B5%E3%83%B3%E3%83%97%E3%83%AB%E3%83%87%E3%83%BC%E3%82%BF.zip)（36.9MB）

### データの中身

- 水道栓開閉栓状況.csv
- 水道使用量.csv
- 住民基本台帳.csv
- 国勢調査.zip
- 空き家調査結果.csv
- 登記.csv
- 建物ポリゴンデータ（PLATEAU）.gpkg
- ジオコーディング済データ.csv
