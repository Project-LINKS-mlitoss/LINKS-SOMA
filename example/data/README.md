# LINKS SOMA サンプルデータ

## サンプルデータについて

本サンプルデータは、LINKS SOMAの各操作を体験していただくために、東京都千代田区の住所をベースに作成したダミーデータです。

詳細な操作方法については、LINKS SOMAの操作マニュアルをご参照ください。

[データをダウンロード](https://storage.googleapis.com/links-soma/example/%E3%82%B5%E3%83%B3%E3%83%97%E3%83%AB%E3%83%87%E3%83%BC%E3%82%BF.zip)（36.9MB）

## 利用時の注意事項

* サンプルデータを利用する際は、**「関東地方」版のSOMA**をご利用ください。
* 本データを用いて空き家推定を実施する場合は、名寄せ処理の設定における**「基準日」を2024年4月1日から2026年4月1日の期間内**で指定してください。

## データの構成

### インプットデータ

以下は、LINKS SOMAへの入力データとして使用するデータです。

* `水道栓開閉栓状況.csv`
* `水道使用量.csv`
* `住民基本台帳.csv`
* `国勢調査.zip`
* `空き家調査結果.csv`
* `登記.csv`
* `建物ポリゴンデータ（PLATEAU）.gpkg`
* `ジオコーディング済データ.csv`
* `推定対象選定用データ.csv`
* `建物関連データ（電力使用量）.csv`

### 名寄せ処理済みデータ

以下は、インプットデータに対してSOMAで名寄せ処理を実施済みのデータです。

* `推定日_2026年04月01日_名寄せ処理済みデータ.csv`
